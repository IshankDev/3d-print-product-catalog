# Shot list

Each image answers one buyer question. Keep product identity locked to the **product photo**. For hero / gift / desk / wall, also attach the matching file from `assets/style-refs/` as a **style** reference.

## Core catalog (01–11) — always generate

| # | Filename suffix | Type | Buyer question | Style ref | Production notes |
|---|-----------------|------|----------------|-----------|------------------|
| 01 | `hero-white` | Marketplace hero | What exactly am I buying? | — | Pure white `#FFFFFF`, ~85% fill, **no text/props** (Amazon/main image) |
| 02 | `three-quarter` | Angled depth | How deep / detailed is it? | — | ~45° view; show shadow-box / print depth |
| 03 | `side-profile` | Profile | What’s the silhouette? | — | Clear side / depth |
| 04 | `detail-macro` | Detail | Does the print look premium? | — | Layer lines, edges, craftsmanship |
| 05 | `scale-hand` | Scale | How big is it? | — | Hand or familiar object |
| 06 | `hero-brand` | Brand marketing hero | Why is this special? | `catalog-hero-style.jpg` | Warm lifestyle bokeh, title, icons, premium catalog layout |
| 07 | `feature-infographic` | Features | What are the benefits? | — | 3–5 callouts / icons |
| 08 | `dimensions` | Specs | What are the measurements? | — | H × W (+ depth if known) |
| 09 | `gift` | Gift / unboxing | Will this feel gift-ready? | `gift-style.jpg` | Kraft box, gold ribbon, festive warm props, gift headlines |
| 10 | `desk` | Desk lifestyle | How does it look on a desk? | `desk-hero-style.jpg` | Wooden desk, office props, size callouts |
| 11 | `wall` | Wall lifestyle | How does it look on a wall? | `wall-hero-style.jpg` | Mounted on wall, console context, dimensions, scale |

## Optional (12) — only if user asks or sells multiple sizes

| # | Filename suffix | Type | Trigger | Notes |
|---|-----------------|------|---------|-------|
| 12 | `size-comparison` | Size chart | “size comparison”, multiple SKUs/sizes | Side-by-side labeled sizes |

## Style system (from WORK18 catalog refs)

Shared look for **06 / 09 / 10 / 11**:

- Warm directional lighting, soft bokeh, premium “heritage × modern” mood
- Product is always the sharpest, brightest subject
- Elegant serif titles + clean sans labels + optional script accent
- Thin circular icon callouts (3–4 max)
- Dark footer badge strip OK: 3D PRINTED · DESIGNED WITH PASSION · MADE IN INDIA (or user brand equivalents)
- Never replace the user’s product with the sample gopuram from style refs

## Gallery order tip (mobile / Etsy)

1. White hero (01) or brand hero (06) → 2. Gift (09) → 3. Desk (10) / Wall (11) → 4. Dimensions / detail → angles

## Category tweaks (3D prints)

- **Framed décor / shadow frames:** always ship desk + wall + gift
- **Functional prints:** desk/in-use > wall; still keep white hero
- **Miniatures / figures:** scale + gift matter most; wall only if mountable
- **Multi-part kits:** detail macro + gift/unboxing inclusions
